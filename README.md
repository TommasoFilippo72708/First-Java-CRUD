# First-Java-CRUD

## Student Management System

A simple console-based Student Management System developed in Java as part of a Java programming assignment.

### Features

- **Add Student:** Add a new student with a name and email address.
- **List Students:** Display all students with their IDs, names, and email addresses.
- **Update Student:** Update an existing student's name and email address.
- **Delete Student:** Remove a student using their ID.
- **Input Validation:** Validate numeric IDs entered by the user.

### Technologies Used

- Java
- Maven
- IntelliJ IDEA

### How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Make sure a compatible JDK is installed.
4. Open `Main.java` located in `src/main/java/pl/edu/vistula/`.
5. Run the `Main` class.
6. Follow the instructions displayed in the console.
